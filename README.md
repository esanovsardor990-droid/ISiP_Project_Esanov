## Описание проекта

Информационная система управления автобазой предназначена для автоматизации учёта работы автобазы, обработки заявок на перевозки, управления транспортом и водителями, учёта рейсов и формирования отчётности.

## Основные возможности

- Учёт клиентов и заявок.
- Учёт водителей и транспорта.
- Регистрация рейсов.
- Учёт маршрутов и оплат.
- Формирование отчётности.
